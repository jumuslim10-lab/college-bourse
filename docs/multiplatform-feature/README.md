## Для человека

### Что это?

Мультиплощадочность — возможность запустить бота на нескольких колледжах/школах одновременно. Каждая площадка видит только свои объявления.

### Зачем?

Масштабирование после успеха на первом колледже. Согласно бизнес-плану (PROMPT.md), это **Фаза 3**, которая включается только после прохождения гейта:
- ≥10 объявлений/день
- ≥5 сделок/неделю
- Две недели подряд

### Что уже работает?

- ✅ База данных готова
- ✅ Миграции работают
- ✅ Методы для работы с площадками есть

### Что нужно доделать?

- ❌ UI для переключения площадок
- ❌ Фильтрация каталога по площадкам
- ❌ Привязка новых объявлений к площадке
- ❌ Инвайт-ссылки (`/start code`)
- ❌ Админка создания площадок

**Оценка:** 3-4 часа работы для опытного разработчика.

## Часто задаваемые вопросы

**Q: Можно ли включить мультиплощадочность сейчас?**  
A: Нет. Согласно PROMPT.md, это Фаза 3. Сначала нужно пройти гейт на текущей площадке.

**Q: Почему `community_id` nullable?**  
A: Для безопасной миграции существующих данных. Старые пользователи и объявления будут с `NULL`.

**Q: Можно ли добавить приём платежей за подписку на площадку?**  
A: **НЕТ.** Жёсткий запрет из PROMPT.md раздел 2. Деньги через бота не проходят никогда.

**Q: Где хранятся бизнес-правила?**  
A: `PROMPT.md` — единый источник правды. 53 КБ текста, но это обязательное чтение.

**Q: Что делать, если не понятно, как реализовать?**  
A: Читать CODE_EXAMPLES.md — там готовый код с точными инструкциями.
